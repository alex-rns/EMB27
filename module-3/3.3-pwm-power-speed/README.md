# Lesson 3.3 — Power and speed control: LED brightness and DC motor speed with PWM

[← Module 3](../)

**Board:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C

Pulse-width modulation: a timer's period sets the frequency, a compare value the duty; the complementary output;
driving a small DC motor through a transistor with a flyback diode; the duty set from a potentiometer through the
ADC interrupt.

## Steps

| # | Step | Type | What it shows |
|---|---|---|---|
| 00 | lecture-pwm: [stm32](00-lecture-pwm-stm32/) | lecture | TIM1 PWM at 10 Hz on PA8 (a 2N2222 and a DC motor) and its inverted CH1N on PA7 (an LED); ADC1 reads a potentiometer in continuous mode, its interrupt hands the value to the main loop, which sets the duty |
