# Lesson 3.3 — Power and speed control: LED brightness and DC motor speed with PWM

[← Module 3](../)

**Boards:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C · ESP32-S3 DevKitC-1 clone (N16R8), ESP-IDF in C
(PlatformIO, `framework = espidf`)

Pulse-width modulation: a timer's period sets the frequency, a compare value the duty; the complementary output;
driving a small DC motor through a transistor with a flyback diode; the duty set from a potentiometer through the
ADC interrupt.

The homework's assignment, translated in full, is in the
[homework step's README](01-homework-pwm-led-motor-esp32/README.md#assignment).

## Steps

| # | Step | Type | What it shows |
|---|---|---|---|
| 00 | lecture-pwm: [stm32](00-lecture-pwm-stm32/) | lecture | TIM1 PWM at 10 Hz on PA8 (a 2N2222 and a DC motor) and its inverted CH1N on PA7 (an LED); ADC1 reads a potentiometer in continuous mode, its interrupt hands the value to the main loop, which sets the duty |
| 01 | homework-pwm-led-motor: [esp32](01-homework-pwm-led-motor-esp32/) | homework | one LEDC timer at 20 kHz, channel 0 drives the motor through a 2N2222 (GPIO 5), channel 1 the LED (GPIO 6, inverted like CH1N); a potentiometer on ADC1 sets both channels' duty every 100 ms; why 20 kHz, the flyback diode across the motor, the motor's starting duty ([assignment](01-homework-pwm-led-motor-esp32/README.md#assignment)) |

## Working with the steps

Every `-esp32` step is an ordinary PlatformIO project on ESP-IDF, written in C: `platformio.ini`, `src/main.c`, the two
`CMakeLists.txt` the PlatformIO wizard makes for ESP-IDF, and `sdkconfig.defaults` (the full `sdkconfig.<env>` is
generated at build time and not tracked).

- **Build / Upload:** open the step's folder in VS Code (or add it to the workspace) and use the PlatformIO buttons,
  or from the terminal: `pio run -d <step-folder>`.
- **Serial Monitor:** the UART USB-C port, 115200 baud (set in `platformio.ini`).

Every `-stm32` step is an STM32CubeIDE project generated by CubeMX: see its README, "Working with the step".
