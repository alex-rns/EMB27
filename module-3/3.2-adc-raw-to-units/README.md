# Lesson 3.2 — From raw ADC readings to degrees and metres: formulas, tables and accuracy

[← Module 3](../)

**Board:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C

Turning an ADC code into a physical value: the voltage, the sensor's formula or table, and how accurate the result
can be; sampling several channels on a timer with DMA, and where the processing belongs.

## Steps

| # | Step | Type | What it shows |
|---|---|---|---|
| 00 | lecture-adc: [stm32](00-lecture-adc-stm32/) | lecture | TIM2 at 1 kHz triggers an ADC1 scan of a potentiometer (PA0) and an LDR (PA1); DMA fills a circular buffer of two halves, the callbacks only count, the main loop averages each finished half and converts it to millivolts |
