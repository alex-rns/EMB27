# Lesson 3.1 — Analog signals: how a microcontroller turns a sensor's voltage into a number

[← Module 3](../)

**Board:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C

The ADC from the voltage to the number: sampling and quantization, the SAR converter and its sample-and-hold, the
sampling rate, Nyquist and aliasing, noise, averaging, and turning a noisy reading into a stable decision with two
thresholds.
