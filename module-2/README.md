## Two boards

Each step's folder ends with its board: `NN-<type>-<slug>-esp32` is a PlatformIO project,
`NN-<type>-<slug>-stm32` is an STM32CubeIDE project. The same number on both boards is the same task, done twice;
each version builds on its own.

| | ESP32 steps | STM32 steps |
|---|---|---|
| Board | ESP32-S3 DevKitC-1 clone (N16R8) | WeAct Black Pill (STM32F411CEU6) + ST-Link V2 over SWD |
| Code | C++, Arduino core 2.0.17 | STM32 HAL, project generated by STM32CubeMX |
| Build | PlatformIO (VS Code) | STM32CubeIDE 2.2.0 |
| Simulation | Wokwi | — |
