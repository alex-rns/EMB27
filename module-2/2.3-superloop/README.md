# Lesson 2.3 — Superloop: several things at once

[← Module 2](../)

**Board:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C

One `while (1)` loop does several things at once: no step waits, each checks the time and acts only when its moment
has come.
