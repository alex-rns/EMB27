# Lesson 2.7 — Mini project on timers

[← Module 2](../)

**Board:** WeAct Black Pill (STM32F411CEU6), STM32CubeIDE, C

The module 2 mini project ties together loads, interrupts, timers and the debounce FSM. Three projects were offered
(a traffic light, an automotive body control module, a DefenceTech arming console); this lesson does the second one.

## Steps

| # | Step | Type | What it shows |
|---|---|---|---|
| 00 | homework-car-controller: [stm32](00-homework-car-controller-stm32/) | homework | a car body controller in a superloop: four debounced FSM buttons (lock / valet, turn signals, hazard lights), a crash sensor on a pin interrupt, a relay through a transistor, a passive buzzer on PWM, turn LEDs blinking at a rate set by a potentiometer on the ADC ([assignment](00-homework-car-controller-stm32/README.md#assignment)) |

## Working with the steps

Every `-stm32` step is an STM32CubeIDE project generated by CubeMX: see its README, "Working with the step".
